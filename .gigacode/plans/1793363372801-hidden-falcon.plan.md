# SocSmile — Прототип соцсети

## Архитектура

- **Backend:** Java 17+ встроенный `com.sun.net.httpserver.HttpServer` (без внешних зависимостей)
- **Frontend:** статические HTML/CSS/JS файлы в `src/main/resources/static/`
- **Хранение:** in-memory (HashMap) — для прототипа, без базы данных
- **API:** REST-подобный JSON (Gson или ручной парсинг)

## Функционал прототипа

1. **Регистрация / Авторизация** — создание аккаунта, вход по логину/паролю
2. **Лента постов** — просмотр постов всех пользователей
3. **Создание постов** — текст + загрузка фото (имитация)
4. **Профиль пользователя** — аватар, имя, список своих постов
5. **Лайки** — возможность ставить/убирать лайки
6. **Сессии** — простое хранение сессий в памяти

## Структура файлов

```
src/
├── Main.java                          — точка входа, запуск сервера
├── controller/
│   └── HttpServerManager.java         — настройка HttpServer и роутинг
├── api/
│   ├── AuthHandler.java               — POST /api/register, POST /api/login
│   ├── PostHandler.java               — GET /api/posts, POST /api/posts
│   ├── LikeHandler.java               — POST /api/posts/{id}/like
│   └── ProfileHandler.java            — GET /api/profile, GET /api/profile/{id}
├── model/
│   ├── User.java                      — id, username, password, avatar, displayName
│   └── Post.java                      — id, authorId, text, imageUrl, likes, timestamp
├── service/
│   ├── UserService.java               — регистрация, авторизация, сессии
│   └── PostService.java               — CRUD постов, лайки
└── util/
    └── JsonUtil.java                  — сериализация/десериализация JSON

src/main/resources/static/
├── index.html                         — главная страница (лендинг)
├── login.html                         — страница входа
├── register.html                      — страница регистрации
├── feed.html                          — лента постов (после входа)
├── profile.html                       — профиль пользователя
├── css/
│   ├── style.css                      — общие стили
│   ├── feed.css                       — стили ленты
│   └── profile.css                    — стили профиля
└── js/
    ├── api.js                         — функции для запросов к API
    ├── feed.js                        — логика ленты
    └── auth.js                        — логика авторизации
```

## Дизайн

- Современный, минималистичный стиль
- Цветовая схема: синий/фиолетовый градиент (как у современных соцсетей)
- Адаптивная верстка (flexbox/grid)
- Карточки для постов
- Навигационная панель сверху

## API Endpoints

| Method | Endpoint              | Описание                  |
|--------|-----------------------|---------------------------|
| POST   | /api/register         | Регистрация пользователя  |
| POST   | /api/login            | Вход в аккаунт            |
| POST   | /api/logout           | Выход из аккаунта         |
| GET    | /api/posts            | Получить ленту постов     |
| POST   | /api/posts            | Создать пост              |
| POST   | /api/posts/{id}/like  | Поставить/убрать лайк     |
| GET    | /api/profile/{userId} | Получить профиль          |
| GET    | /api/me               | Получить текущего пользователя |

## План реализации

### Шаг 1: Модели данных
- `User.java` — id, username, password, avatar, displayName, createdAt
- `Post.java` — id, authorId, text, imageUrl, likeIds[], createdAt

### Шаг 2: Сервисы (логика)
- `UserService` — хранение пользователей, проверка уникальности, создание сессий
- `PostService` — хранение постов, CRUD, лайки

### Шаг 3: HTTP Handlers
- `AuthHandler` — регистрация/вход/выход
- `PostHandler` — получение и создание постов
- `LikeHandler` — лайки
- `ProfileHandler` — профили

### Шаг 4: Сервер
- `HttpServerManager` — настройка сервера на порту 8080, статические файлы

### Шаг 5: Frontend
- `style.css` — базовые стили, переменные, навбар
- `login.html` / `register.html` — формы входа/регистрации
- `feed.html` — лента с карточками постов, форма создания поста
- `profile.html` — страница профиля
- `api.js` — fetch-обёртки для API
- `auth.js` — управление сессией, редиректы
- `feed.js` — рендеринг ленты, лайки

### Шаг 6: Тестирование
- Запуск сервера
- Регистрация → вход → создание поста → лайк → просмотр профиля

## Верификация

1. `javac` компиляция всех файлов
2. Запуск `java Main` — сервер на порту 8080
3. Открыть `http://localhost:8080` — лендинг
4. Зарегистрировать пользователя, войти
5. Создать пост, поставить лайк
6. Проверить отображение профиля
